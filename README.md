# 🚀 Resume Screening System (AI-Based ATS Tool)

A Flask-based intelligent **Resume Screening System** that evaluates resumes based on selected job roles using skill matching and ATS-style scoring.

The system extracts candidate details, matches required skills, and classifies resumes as **Selected or Rejected**.

---

## 📌 Project Objective

- Automate resume screening process
- Match resumes with job role requirements
- Calculate ATS-style score
- Identify matched and missing skills
- Improve recruitment efficiency

---

## 🎯 Features

- 📄 Upload Resume (PDF / DOCX / TXT)
- 🎯 Select Job Role
- 🧠 Skill Extraction from Resume
- 🔍 Job Role-Based Skill Matching
- 📊 ATS Score Calculation
- ✅ Selected / ❌ Rejected Classification
- 📧 Email Extraction
- 👤 Candidate Name Extraction
- 🧩 Matched & Missing Skills Display
- 🏆 Certification Detection (if present in resume)

---

## ⚙️ Project Workflow

### 1. Resume Upload
User uploads resume in PDF/DOCX/TXT format.

### 2. Text Extraction
Extracts text from uploaded resume using file parsers.

### 3. Skill Matching
Compares resume skills with job role requirements.

### 4. ATS Score Calculation
Score calculated based on matched skills percentage.

### 5. Result Generation
Displays:
- Candidate details
- Score
- Status
- Matched & Missing skills

---
